# 音频结构分析方法论：Ap / Dp / S / Cp 段落判定

> 本文档是整个框架的「大脑」。目标：给定一首歌的音频（mp3/wav），用任何可用的手段，把时间轴切分成段落，并为每段打上四类标签之一；同时输出 BPM、拍点、强拍与每一次 kick 事件。
>
> 标签定义（音乐结构分析 / Music Structure Analysis 语境）：
> - **Ap（主歌段落 / Verse）**：叙事性段落，歌词密集、能量相对平缓，为副歌做铺垫。
> - **Dp（铺垫段落 / Pre-Chorus / Build）**：主歌向副歌过渡的「爬坡」段，能量、和声张力、编曲密度逐步抬升。
> - **S（副歌段落 / Chorus）**：全曲记忆点，旋律最「抓耳」、重复度最高、能量峰值、人声与编曲最满。
> - **Cp（副歌后段落 / Post-Chorus）**：紧跟副歌的收尾/回落段，承接副歌能量并过渡回主歌或间奏。

---

## 1. 总原则

段落判定不能靠单一特征，而要靠**多特征加权 + 时序约束**。核心思想：

1. 先把音频切成一串**均匀的时间块（segment）**，每块约 0.5~4 秒（推荐 beat-aligned）。
2. 为每块计算一组**特征向量**。
3. 用**和声结构（chroma）层次聚类**做结构分割（外层结构可靠可测）。
4. 把分割出的「结构片段」归并成「段落」。
5. 用**规则分类器**（辅以可选的 ML 分类器）给每个段落打标签。

优先级：**先做对「切分」再谈「打标签」**。切分错了，标签一定错。

**重要经验（已实测验证）：**

- 「外层结构」边界（intro→主歌→副歌/drop→breakdown）**可靠可测**，chroma 层次聚类 + 能量突变即可。
- 「副歌内部的细分」边界（S1→S2）是音乐**曲式/乐句层面的语义边界**——两个副歌段在能量、和声、kick 节奏上几乎完全相同，任何单一低层声学特征（含预训练 embedding 的 novelty）都无法稳定区分，属曲式分析（form analysis）范畴，需要更强先验或人工锚点。

## 2. 节奏：BPM、拍网格与 kick

### 2.1 BPM 检测

主通道用**低频（kick/bass，<120Hz）能量自相关**：kick 最规整，octave 歧义最小。辅通道用 onset 强度包络自相关做交叉验证（窄拍长区间）。两个通道结果接近（差 <8%）即采纳。

### 2.2 拍网格相位估计（「一拍」的概念）

**核心直觉：用频谱特征把握「一拍」，而不是用 kick 单点锚定。**

- kick 峰值检测在副歌段会因 off-beat 弱击打 + 低频能量形态变化而系统性偏移（实测 intro 相位 0.093s vs 副歌 0.139s，差 46ms）；
- **onset_strength（全频谱起音）**反映「一拍」的感知起音，不受低频 off-beat 干扰。

做法：对 onset 峰值做**圆平均相位**估计——把每个 onset 峰值时间对拍周期取模映射到单位圆，用向量平均求主相位。正拍 onset 相位一致、噪声均匀散布，因此对 off-beat / 漏检 robust。

### 2.3 均匀拍网格

锁定 BPM + 相位后，**全局均匀推进**拍网格（拍长恒定 ≈ 60/BPM），不再逐拍吸附 kick。这样：

- 拍长严格均匀，符合「原曲匀速 beat」的预期；
- 不会被副歌 off-beat 弱 kick 拉偏。

> 实测：`guy_contact.wav` 上 123.1 BPM，Ap（0–39s）正好 80 拍、20 小节，与金标准完全一致。

### 2.4 kick 事件检测（独立于拍网格）

低频（40~120Hz）能量包络 + `find_peaks`（距离 ≥0.2s、相对 prominence ≥5%），得到**每一次真实 kick**（含正拍 + off-beat 弱击打），作为独立事件列表输出，与拍网格解耦。

## 3. 特征指标体系（Feature Set）

| 特征 | 含义 | Ap | Dp | S | Cp |
|---|---|---|---|---|---|
| **能量 / RMS** | 响度包络 | 中低 | 中→高（爬升） | **高（峰值）** | 高→中（回落） |
| **频谱质心** | 亮度 | 中 | 上升 | 高 | 高→中 |
| **频谱带宽** | 频谱展宽，编曲丰满度 | 窄 | 变宽 | **宽（最满）** | 宽→窄 |
| **频谱通量** | 帧间变化率 | 低 | 中 | 中高 | 中 |
| **和声结构（chroma）** | 和弦循环 | 稳定 | 变化加速 | 稳定 loop | 稳定 |
| **低音能量占比** | 低频占比 | 中 | 中高 | 高 | 中高 |
| **重复结构** | 全曲出现次数 | 若干 | 若干 | **最多、最规律** | 跟随副歌 |

> 框架默认用**相对值（全曲归一化排名）**而非绝对值，以降低曲风差异影响。

## 4. 分析管道（Pipeline）

```
音频文件
  └─ 1) 加载与预处理 (io)
       ├─ soundfile 解码 → 单声道 → 重采样 (22050Hz)
       ├─ 静音裁剪 → 响度归一
  └─ 2) 特征提取 (features)
       ├─ 帧级：RMS、频谱质心/带宽/通量、chroma、MFCC
       ├─ 块级聚合（均值/标准差/斜率）
       └─ 可选：Demucs 声部分离 → 结构 embedding
  └─ 3) 结构分割 (segmentation)
       ├─ chroma 层次聚类（和声结构）+ 能量低谷（breakdown）
       └─ 节拍：BPM + 拍网格 + kick 事件
  └─ 4) 段落归并 (classification)
       ├─ 按边界归并为段落
       ├─ 重复段聚类（副歌候选）
       └─ 规则分类 + 时序约束 → Ap/Dp/S/Cp
  └─ 5) 输出 (io)
       └─ AnalysisResult → JSON + 可视化播放器
```

## 5. 四类段落的判定规则

### 5.1 前提：结构聚类

- 用 chroma 直方图 + MFCC 均值作为段落特征，算余弦相似度矩阵；
- 用「中位数 + 3×MAD」动态阈值聚类；
- **出现次数最多、组内相似度最高**的那组 → 候选「副歌 S」。

### 5.2 S（副歌）判据

1. 属于重复段落组（出现 ≥2 次）。
2. 能量 / 频谱质心处于全曲**高位（top ~45%）**。
3. 人声存在性强且稳定（若有声部分离）。

### 5.3 Dp（铺垫）判据

1. 紧邻在某个 S 之前（时序约束）。
2. **能量单调爬升**（段内 RMS 首尾对比 slope > 阈值）。

### 5.4 Ap（主歌）判据

1. 位于 S 之前。
2. 能量**中低**，明显低于相邻 S。
3. 编曲密度较低。

### 5.5 Cp（副歌后）判据

1. **紧跟某个 S 之后**（时序约束，最强判据）。
2. 能量从峰值回落。

---

## 6. 时序约束（Timeline Constraints）

- 合法的大致序列：`(Intro) → Ap → Dp → S → Cp → (Interlude) → Ap → Dp → S → Cp → (Outro)`。
- S 必须出现 ≥ 1 次；若多次，应等距分布。
- Dp 只能出现在 S 之前，Cp 只能出现在 S 之后。
- 若违背，按置信度从低到高回溯修正。

---

## 7. 可选的机器学习增强

- 特征：块级特征 + 段落级统计量。
- 标签：Ap/Dp/S/Cp（+ 可选 Intro/Interlude/Outro/Bridge）。
- 模型：优先逻辑回归 / 随机森林 / GBDT（可解释、小样本稳）。
- 序列解码：HMM / CRF 平滑标签序列（Ap→Dp→S→Cp 转移链）。
- 曲式细分：S1→S2 需要更强的 repetition 结构建模或人工锚点。

## 8. 关键依赖

- `librosa`：频谱、chroma、MFCC、onset、层次聚类。
- `numpy` / `scipy`：矩阵、峰值拾取、自相关。
- `sklearn`：聚类与分类器。
- （可选）`torch` / `torchaudio`：Demucs 声部分离。
- （可选）`soundfile`：稳健 mp3 解码。

---

## 9. 评价方式（Evaluation）

- **人工标注基准**：N 首歌的人工段落标注（边界 + 标签）。
- **边界指标**：Hit Rate（预测边界与真实边界 ±0.5s / ±3s 容差）。
- **标签指标**：段落级 F1（尤其关注 S 的召回——漏副歌比错分主歌更严重）。
- **节奏指标**：BPM 绝对误差、拍点对齐误差、小节数匹配。

## 10. 已知难点与对策

| 难点 | 对策 |
|---|---|
| 曲风差异大（绝对值不可比） | 全曲归一化相对值 |
| 副歌 off-beat 弱 kick 拉偏拍网格 | 用全频谱 onset 相位 + 均匀网格，不吸附 kick |
| 副歌内部细分（S1→S2） | 曲式语义边界，需更强先验或人工锚点 |
| 边界不齐（过渡而非某帧） | 边界对齐到拍/小节网格 |
| 前奏/间奏/尾奏干扰 | 归入 Intro/Interlude/Outro 非目标标签 |
| 无歌词时主歌 vs 副歌难分 | 能量 + 编曲密度 + 旋律重复度组合 |
